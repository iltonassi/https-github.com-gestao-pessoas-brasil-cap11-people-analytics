# https-github.com-gestao-pessoas-brasil-cap11-people-analytics     
Material Complementar – Capítulo 11: People Analytics (Livro: Gestão de Pessoas nas Empresas Contemporâneas Brasileiras). Contém códigos R comentados, 7 Datasets fictícios, mais muito similares aos reais e roteiros passo a passo para replicação das análises de risco de turnover.     
    
📊 **Capítulo 11: People Analytics – Da Teoria à Prática com R**     
    
Bem-vindo ao repositório oficial de materiais complementares do Capítulo 11: People Analytics.     

Este ambiente foi criado para apoiar estudantes, professores e gestores de RH na transição do conceito teórico para a aplicação prática da análise de dados em Gestão de Pessoas.
Aqui você encontrará todos os recursos necessários para replicar as análises apresentadas no livro, permitindo que você "coloque a mão na massa" e construa seus próprios modelos preditivos de retenção de talentos.     

📂 O Que Há Neste Repositório?
Este repositório está organizado em quatro pastas principais para facilitar sua jornada de aprendizado:
• 01-codigos-r/: O script completo (analise_turnover.R) utilizado no capítulo. O código possui mais de 250 linhas comentadas passo a passo, cobrindo desde a limpeza dos dados até a criação do modelo de Regressão Logística e a Matriz de Confusão.    

• 02-datasets/:
    ◦ Conjunto de 6 arquivos CSV com dados fictícios, mas muito próximos à realidade do setor de saúde.
    ◦ Inclui dados históricos de 9 anos, cobrindo variáveis demográficas, de desempenho, satisfação e movimentação de pessoal.    
    
• 03-documentacao/:
    ◦ Dicionário de Dados: Explicação detalhada das 62 variáveis presentes nos datasets.
    ◦ Guia de Instalação: Instruções para configurar o ambiente R e RStudio.    
    
• 04-exercicios/: Caderno de exercícios práticos com gabaritos para fixação do conteúdo (ideal para uso em sala de aula).    

🚀 Como Usar Este Material
Não é necessário ser um programador experiente. O material foi desenhado com foco didático:
1. Cole ou Baixe este repositório (clique no botão verde <> Code e selecione Download ZIP).   
2. Abra o arquivo analise_turnover.R no RStudio.
3. Siga os comentários no código. Eles funcionam como um tutorial guiado, explicando a lógica de negócio por trás de cada função estatística.
   
🎯 Objetivos de Aprendizado
Ao final da exploração deste material, você será capaz de:
1. Unificar Fontes de Dados: Realizar o Data Wrangling unindo dados de cadastro, folha de ponto e pesquisa de clima.
2. Analisar Riscos: Criar visualizações (histogramas e curvas de densidade) para entender o comportamento das horas extras e satisfação.
3. Prever Saídas: Treinar um algoritmo de Machine Learning para calcular a probabilidade de saída de colaboradores específicos (como nos casos estudados de "Keith Ward" e "Linda Medina").
4. Tomar Decisões: Utilizar a Matriz de Confusão para definir estratégias de intervenção baseadas em dados (Corte de 30% vs 50%).
